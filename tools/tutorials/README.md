# Documentation tutorial recordings

The first narrated tutorials cover account setup and onboarding, as requested by the user:

- `account-setup/`: complete an invited account's setup.
- `agency-onboarding/`: review agency configuration and invite/prepare an agent.

Each directory owns its recorder, guarded fictional fixtures, measured scene timing and exact narration script. Raw footage and review frames stay in ignored output directories. Use only the isolated local demo and source-verified actions. The app revision is recorded with each tutorial.

Final OpenAI narration, synchronization, captions and page embedding are handled by `../narration/`. Completed videos use click-to-play controls, an AI narration label, English captions and a transcript near the page introduction. Keep existing written steps below the tutorial.
