Create task templates so your team can reuse a title and description. Templates appear in the **Add Task** form once saved.

## Before you start

- Choose a template name your team will recognize.
- Prepare the title and details that should appear in each new task.

<Steps>
  <Step title="Open task templates">
    In **Tasks**, select **Templates**.
  </Step>
  <Step title="Add a template">
    Select **Add Template**. The **New task template** form opens.

    <Frame>
      <img src="/images/settings/task-template-form.png" alt="New task template form with Template name, Task title, and Task details fields." />
    </Frame>
  </Step>
  <Step title="Name the template">
    In **Template name**, enter the name your team will use to find it.
  </Step>
  <Step title="Enter the task title">
    In **Task title**, enter the action the task should describe.
  </Step>
  <Step title="Add task details">
    In **Task details**, enter reusable instructions or background information.
  </Step>
  <Step title="Create the template">
    Select **Create template**.
  </Step>
</Steps>

## What you'll see

Your template appears in **Task Templates** and becomes available through **Template** when creating tasks.

Use a template's **Edit** action to change its fields, then select **Save changes**. Use **Delete** to remove an unwanted template.

## If it didn't work

<AccordionGroup>
  <Accordion title="Create template is disabled">
    Enter both **Template name** and **Task title**. Neither field can be blank.
  </Accordion>
  <Accordion title="A field has an error">
    Keep the name and title within 255 characters each, and task details within 10,000 characters.
  </Accordion>
  <Accordion title="The template list is empty">
    Create your first template. Agents can use templates, but Admins and Agency Owners manage them.
  </Accordion>
</AccordionGroup>
