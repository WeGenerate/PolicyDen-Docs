<Info>**Who can do this:** Individual agent account holders can edit their own assignments. Agency Admins and Agency Owners manage assignments from the user’s main agency.</Info>

Record licensed states and contracted carriers by product. Products and available upline carriers must already be set up.

## Before you start

- In an individual agent account, open your own **Profile**.
- In an agency, open **Users**, then the user’s **View Profile** action.
- Switch to the user’s main agency if the profile asks you to do so.

<Steps>
  <Step title="Open licensed states">
    On the profile, select **Licensed States**.

    <Frame>
      <img src="/images/settings/licensed-states-and-contracts-overview.png" alt="Individual profile with Licensed States highlighted." />
    </Frame>
  </Step>
  <Step title="Choose the licensed states">
    For each product, use **Select states** to choose the states where the agent is licensed.
  </Step>
  <Step title="Save licensed states">
    Select **Save**.
  </Step>
  <Step title="Open carrier contracts">
    Select **Contracts**.
  </Step>
  <Step title="Choose contracted carriers">
    For each product, use **Select carriers** to choose contracted carriers.
  </Step>
  <Step title="Choose each upline">
    For each selected carrier, choose its **Upline source** when one is not already selected.
  </Step>
  <Step title="Save carrier contracts">
    Select **Save**.
  </Step>
</Steps>

## What you'll see

The profile shows saved states and carriers for each product; contracted carriers are available when adding policies.

For marketplace accounts, licensed states also affect which state’s calls can route to the agent.

## If it didn't work

<AccordionGroup>
  <Accordion title="No products appear">
    The page says “No products are set up on this account yet.” [Set up products](/settings/products-and-carriers) first.
  </Accordion>
  <Accordion title="No upline carriers appear">
    Accept an upline invitation or ask the upline to add carriers. See [relationships](/settings/relationships).
  </Accordion>
  <Accordion title="Save is unavailable">
    Choose an upline source for every selected carrier. If nothing changed, there is nothing to save.
  </Accordion>
</AccordionGroup>
