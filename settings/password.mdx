<Info>**Who can do this:** Agents, Admins, and Agency Owners can update their own profile.</Info>

Change your sign-in password from the Security tab. You need your current password to save a new one.

<Steps>
  <Step title="Open security settings">
    In **Profile**, select **Security**.

    <Frame>
      <img src="/images/settings/password-overview.png" alt="Profile Security tab with the Password section." />
    </Frame>
  </Step>
  <Step title="Enter your current password">
    In **Password**, enter **Current Password**.
  </Step>
  <Step title="Enter a new password">
    Enter **New Password** using at least eight characters, uppercase and lowercase letters, and a special character.
  </Step>
  <Step title="Confirm the new password">
    In **Confirm Password**, enter the same new password.
  </Step>
  <Step title="Save your password">
    Select **Save**.
  </Step>
</Steps>

## What you'll see

A confirmation says **Password updated** after the change succeeds. Use the new password the next time you sign in.

## If it didn't work

<AccordionGroup>
  <Accordion title="The current password is incorrect">
    Enter the password you currently use to sign in. If you forgot it, follow [sign-in help](/fix/sign-in-problems).
  </Accordion>
  <Accordion title="The passwords do not match">
    Enter the same value in both new-password fields and check every requirement shown.
  </Accordion>
  <Accordion title="The save keeps failing">
    Wait before retrying repeated attempts. Password changes are rate-limited; contact support if the error continues.
  </Accordion>
</AccordionGroup>
