<Info>**Who can do this:** Admins and Agency Owners in agency accounts. Individual agent accounts have no Users page.</Info>

Open a user profile to update personal and employment details. Use the appropriate section’s Save button after each change.

<Steps>
  <Step title="Open the user profile">
    In **Users**, open the user’s actions menu and select **View Profile**.

<Frame caption="User profile with the Details tab.">
  <video className="w-full rounded-xl motion-reduce:hidden" autoPlay muted loop playsInline controls preload="metadata" poster="/images/settings/user-profiles-overview.png" src="/videos/settings/user-profiles.mp4" aria-label="User profile with the Details tab." />
  <img className="hidden motion-reduce:block" src="/images/settings/user-profiles-overview.png" alt="User profile with the Details tab." />
</Frame>
  </Step>
  <Step title="Open employment details">
    Select **Details** and find **Employment**.
  </Step>
  <Step title="Update the user settings">
    Change **Status**, **Role**, **Sales Channel**, or **Employment Type** as needed.
  </Step>
  <Step title="Set telesales location">
    For **Telesales (Call center)**, choose **In-Office** or **Remote** in **Work Location**.
  </Step>
  <Step title="Set training access">
    For an **Agent**, turn **Training** on or off as needed.
  </Step>
  <Step title="Save employment changes">
    In **Employment**, select **Save**.
  </Step>
</Steps>

**Training** gives Agents listen-only access to **Live Monitor** when the agency has the dialer enabled. It does not change their role.

The **Details** tab also holds personal, license, address, banking, and document sections. **Settings** includes **Business Card** images and **vCard** contact cards stored on the agent’s profile.

Use [licenses and contracts](/settings/licensed-states-and-contracts) for product assignments and [access and security](/settings/user-access-and-security) for password or login controls.

## What you'll see

The profile shows the saved employment settings; the role applies to the user’s main agency.

## If it didn't work

<AccordionGroup>
  <Accordion title="Work Location is hidden">
    Select **Telesales (Call center)** in **Sales Channel** to show it.
  </Accordion>
  <Accordion title="Training is hidden">
    The **Training** switch appears only when **Role** is **Agent**.
  </Accordion>
  <Accordion title="The profile will not load">
    Retry the load and confirm that the user belongs to the agency you are managing.
  </Accordion>
</AccordionGroup>
