The header bell shows task notifications. Banners show wallet warnings or tell you when you're working as another user.

<Steps>
  <Step title="Open your notifications">
    In the header, select the bell icon.
        <Frame>
          <img src="/images/getting-started/notifications-open.png" alt="Notifications menu showing task updates and Mark all read." />
        </Frame>
  </Step>
  <Step title="Review a task update">
    Select a notification to mark it read and open its linked page, when available.
  </Step>
  <Step title="Clear the unread count">
    To mark every notification read, select **Mark all read**.
  </Step>
</Steps>

Notifications identify task assignments and completions, the person involved, and when the update happened. Unread items have a tinted background. The bell badge shows **9+** when there are more than nine unread items.

## Respond to banners

**Your wallet is empty.** means marketplace calls are paused until funds are added. A low-balance banner shows the current balance. Admins and Agency Owners can use **Add funds**; see [wallet funds](/settings/wallet-funds).

**You are logged in as** names the user whose account you're viewing. Select **Switch back to** your name to leave that view.

## What you'll see

Read notifications lose their unread highlight, and the bell count updates.

## If it didn't work

<AccordionGroup>
  <Accordion title="The menu says You're all caught up">
    There are no notifications to display. This menu covers task updates; texts are in [Messages](/messages/overview).
  </Accordion>
  <Accordion title="Notifications won't load">
    For **Could not load notifications.**, reopen the bell menu. If it persists, email support@policyden.com with the time and error.
  </Accordion>
  <Accordion title="Mark all read failed">
    For **Could not mark notifications as read.**, try again. If the error continues, reload the page and contact support.
  </Accordion>
</AccordionGroup>
