**Saved filters** turn a set of filters, columns, and sort order into a named view you can reopen in a click. Use them on the **Contacts**, **Policies**, and **Tasks** list pages.

## Save a filter

<Steps>
  <Step title="Set up the view">
    Open **Filters** in the toolbar, build the filter rows you want, and click **Apply**. Sort and customize columns while you're at it — the saved filter captures those too.
  </Step>
  <Step title="Open the save popover">
    With **Filters** open, click **Save Filter** in the header.
  </Step>
  <Step title="Name it and pick visibility">
    Enter a name. Choose **Visible to you only** to keep it private, or **Share with** to pick teammates who should see it.
  </Step>
  <Step title="Save">
    Click **Save Filter**. The view now appears in the **Saved Filters** dropdown at the top of the filters popover.
  </Step>
</Steps>

## Use a saved filter

Open **Filters** on the list and pick a view from the **Saved Filters** dropdown. The list reloads with the saved filter rows, sort, and columns applied.

<Tip>
  Saved filters remember the exact filter values, not a relative range. If you save "Sold this month," you may want to re-save it at the start of each month.
</Tip>

## Edit a saved filter

With the saved filter selected, open **Filters** and change anything — add or remove rows, pick a new sort. Click **Edit Filter** in the header to update the saved view. You can only edit filters you own.

## Share a saved filter

You can share a filter when you save it, or from the save popover later:

<Steps>
  <Step title="Open the saved filter">
    Pick the filter from the **Saved Filters** dropdown.
  </Step>
  <Step title="Open the save popover">
    Click **Edit Filter** in the filters popover header.
  </Step>
  <Step title="Switch to Share with">
    Change the visibility to **Share with**, then select the teammates who should see it.
  </Step>
  <Step title="Save">
    Click **Save Filter**. Shared users see the view in their own **Saved Filters** dropdown.
  </Step>
</Steps>

<Note>
  Only the person who created a filter can edit, share, or delete it. Teammates who received a shared filter can select it but not modify it.
</Note>

## Delete a saved filter

With the saved filter selected, click the trash icon next to the **Saved Filters** dropdown in the filters popover. This removes the filter from every user it was shared with.

## Reports have their own saved views

The **Reports** page has a separate **Saved Reports** list that works the same way — you save a report with a name, share it, and switch between reports from the breadcrumb. See [Reports overview](/reports/overview) for details.
