<Info>**Who can do this:** Agents, Admins, and Agency Owners with access to the contact.</Info>

Upload a file to a contact's **Documents** tab. You can rename it, download it, or link it to a policy.

## Before you start

- Upload one file at a time, up to 100MB.
- Supported formats: TXT, PDF, DOC, DOCX, XLS, XLSX, CSV, PPT, PPTX; JPG, JPEG, PNG, GIF, WEBP, SVG; ZIP, RAR, 7Z; MP4, AVI, MOV, WMV; MP3, WAV, FLAC.

## Manage an uploaded file

<Steps>
  <Step title="Open or download it">
    Select **Preview** for an image, PDF, or TXT file. Select **Download** to save a copy.
  </Step>
  <Step title="Rename the file">
    Select the file name twice quickly, enter a new name, then press Enter. The file extension stays unchanged.
  </Step>
  <Step title="Link a policy">
    Select **Link to Policy**, then choose a policy belonging to this contact.

    Use **Change Policy** to choose another policy, or **Remove link** to unlink it.
  </Step>
</Steps>

To remove a file from the list, select **Archive**, then **Archive file** in the **Archive File** dialog.

<Warning>Archived files disappear from the list. There is no restore control in the app.</Warning>

## What you'll see

The document card shows the file name and any linked policy; notes and comments can hold their own attachments too.

## If it didn't work

<AccordionGroup>
  <Accordion title="My file won't upload">
    Check its extension and size against the supported formats. Upload one file at a time.
  </Accordion>
  <Accordion title="Preview is missing or fails">
    Preview supports images, PDF, and TXT only. If it cannot load, select **Download** instead.
  </Accordion>
  <Accordion title="No policies appear">
    Only policies belonging to this contact are available. You can leave the document unlinked.
  </Accordion>
</AccordionGroup>
