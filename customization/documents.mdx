Every contact and policy has a **Docs** tab where you can attach files — signed applications, ID photos, correspondence, SOAs, anything you want tied to the record.

## Where documents live

| Location | What belongs there |
| -------- | ------------------ |
| **Contact → Docs** | Files about the client: ID, SOA, email attachments, enrollment paperwork. |
| **Policy → Docs** | Files specific to one policy: the application, the EOB, cancellation paperwork. |

Files uploaded on a contact stay with the contact. Files uploaded on a policy stay with the policy, even if the contact has multiple policies.

## Upload a file

<Steps>
  <Step title="Open the Docs tab">
    From the contact or policy profile, click the **Docs** tab.
  </Step>
  <Step title="Drop or browse">
    Drag a file onto the drop zone, or click the drop zone to open the file picker.
  </Step>
  <Step title="Wait for the upload">
    The file appears in the list when the upload finishes. The name, size, uploader, and timestamp show on the card.
  </Step>
</Steps>

<Info>
  Files are capped at **10 MB each**. Supported formats: PDF, Word, Excel, CSV, text, images (PNG, JPG, GIF, WEBP, SVG), archives (ZIP, RAR, 7Z), audio (MP3, WAV, FLAC), video (MP4, MOV, AVI, WMV), and PowerPoint.
</Info>

## Download a file

Click the **Download** action on the file card. The file opens in a new tab using a short-lived secure link.

## Rename a file

Use the rename action on the file card. Type the new name and press Enter. The extension is kept as-is.

## Delete a file

Click the archive action on the file card and confirm. The file is removed from the record.

<Warning>
  Deletion is immediate and can't be undone. If you're not sure, rename or leave it alone.
</Warning>

## Attach files to a note or comment

You can also attach files inline when you write a note or a comment:

- **Notes** — use the paperclip in the note editor. See [Notes and comments](/customization/notes-and-comments).
- **Comments** — attach files to a comment so they travel with the discussion.

Files attached to a note or comment don't appear in the contact's or policy's main Docs tab. They stay with the note or comment.
