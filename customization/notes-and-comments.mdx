<Info>**Who can do this:** Agents, Admins, and Agency Owners with access to the contact.</Info>

Create a note for contact details that need more space. Use its comment thread for follow-up discussion.

## Create a note

<Steps>
  <Step title="Open the note form">
    Open the contact and select **Add Note** in the profile header.
<Frame caption="Add Note dialog with Link to Policy.">
  <video className="w-full rounded-xl motion-reduce:hidden" autoPlay muted loop playsInline controls preload="metadata" poster="/images/customization/add-note.png" src="/videos/customization/add-note.mp4" aria-label="Add Note dialog with Link to Policy." />
  <img className="hidden motion-reduce:block" src="/images/customization/add-note.png" alt="Add Note dialog with Link to Policy." />
</Frame>
  </Step>
  <Step title="Enter your note">
    Enter **Note Title** and **Add Description...**.
  </Step>
  <Step title="Attach supporting files">
    Optionally select **Attach file**. You can attach up to 10 files, each up to 100MB.
  </Step>
  <Step title="Link a policy">
    Optionally select **Link to Policy**, then choose one of the contact's policies.
  </Step>
  <Step title="Create the note">
    Select **Create Note**.
  </Step>
</Steps>

## Edit or discuss a note

<Steps>
  <Step title="Open the note details">
    In the contact's **Notes** tab, select a note card to open **Note Details**.
  </Step>
  <Step title="Update the note">
    Select its title or content to edit. Select **Save** when finished, or **Cancel** to discard changes.

    You can also attach files and change or remove the linked policy.
  </Step>
  <Step title="Add a comment">
    Enter your message in **Leave a comment...**, then select the send icon.

    Your own comments have **Edit** and **Delete** menu options. Comments can also contain attachments.
  </Step>
</Steps>

## What you'll see

The **Notes** tab shows note cards with their author, date, linked policy, and attachment count.

<Warning>**Delete** on a note card permanently deletes the note and its attachments. The **Archive** action in **Note Details** also deletes the note.</Warning>

## If it didn't work

<AccordionGroup>
  <Accordion title="No policies appear to link">
    **No policies found.** means this contact has no available policies to select. You can create the note without a policy link.
  </Accordion>
  <Accordion title="An attachment failed to upload">
    Open the saved note and check its attachments before retrying. See [document limits](/customization/documents).
  </Accordion>
  <Accordion title="I can't edit a comment">
    The comment menu displays **Edit** and **Delete** only for comments you wrote.
  </Accordion>
</AccordionGroup>
