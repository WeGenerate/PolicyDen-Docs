<Info>**Who can do this:** Admins and Agency Owners, including the owner of an individual agent account.</Info>

Create a pipeline for a sales process, then name and arrange its stages. Your agency's Agents use these stages when moving deals.

## Create a pipeline

<Steps>
  <Step title="Open the create form">
    In **Pipelines**, select **Create Pipeline** from the pipeline name dropdown. An empty page shows this button directly.
  </Step>
  <Step title="Name your pipeline">
    Enter a **Pipeline Name** that helps your team identify the process.
  </Step>
  <Step title="Create the board">
    Select **Create Pipeline**. The new board opens.
  </Step>
</Steps>

New pipelines start with **Qualified**, **Contact Made**, and **Proposal Made**.

## Configure the stages

<Warning>Removing a stage removes its deals from this pipeline when you save. The contacts themselves remain in PolicyDen.</Warning>

<Steps>
  <Step title="Open pipeline settings">
    In the board header, select the settings icon to open **Configure Pipeline**.
        <Frame caption="Use pipeline settings to name and arrange stages.">
          <img src="/images/pipeline/configure-stages.png" alt="Configure Pipeline dialog showing the pipeline name, stage rows, and Save Pipeline button." />
        </Frame>
  </Step>
  <Step title="Update the names">
    Edit **Pipeline Name** or the **Stage Name** fields.
  </Step>
  <Step title="Choose stage markers">
    Select the small marker before a stage name to choose its appearance.
  </Step>
  <Step title="Arrange the stages">
    Drag a row's handle to change the stages' left-to-right order on the board.
  </Step>
  <Step title="Adjust the stage list">
    Use the plus row to add a stage, or a stage's trash icon to remove it.
  </Step>
  <Step title="Save your changes">
    Select **Save Pipeline**.
  </Step>
</Steps>

## Delete a pipeline

Select the trash icon in the board header to open **Delete Pipeline?**, then confirm the deletion.

<Warning>Deleting a pipeline permanently removes the board and all its stages. This action can't be undone.</Warning>

## What you'll see

Your saved stage names, markers, and order appear on the board for your agency.

## If it didn't work

<AccordionGroup>
  <Accordion title="I don't see pipeline settings">
    Only Admins and Agency Owners can create, configure, or delete pipelines.
  </Accordion>
  <Accordion title="Save Pipeline is unavailable">
    Enter a nonblank pipeline name and a name for every stage, including newly added stages.
  </Accordion>
  <Accordion title="The changes didn't save">
    If you see **Failed to save**, reopen settings and check which changes remain before trying again.
  </Accordion>
</AccordionGroup>
