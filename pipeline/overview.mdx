**Pipelines** shows contacts as deal cards, grouped into stages. Each pipeline has its own board, so you can track different sales processes separately.

<Frame caption="A pipeline board groups your deals by stage.">
  <img src="/images/pipeline/overview-board.png" alt="Pipelines board showing stage columns, deal cards, and the pipeline name dropdown." />
</Frame>

Go to **Pipelines** in the sidebar. Use the pipeline name dropdown to switch boards when your agency has more than one pipeline. Admins and Agency Owners also see this dropdown when there's only one pipeline.

Each column shows a stage marker, name, and card count. The **Leads** tag beside the pipeline name counts cards on the board.

A card shows the contact's name and Medicare Beneficiary Identifier (MBI), when available. See the [glossary](/start/glossary) for insurance terms. Select the name to open the contact's profile. Agency accounts also show an assigned-agent tag when the contact has an assigned agent.

## Who sees what

Agents see and manage deals for contacts assigned to them. Admins and Agency Owners see all deals and can create, configure, or delete pipelines. An individual agent account has Admin rights and doesn't show assigned-agent tags on cards.

If you see **No pipelines yet**, ask an Admin or Agency Owner to create one. **No stages configured** means that the selected pipeline needs stages before you can add deals.
