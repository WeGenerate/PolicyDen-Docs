<Info>**Who can do this:** Admins and Agency Owners, including owners of individual agent accounts.</Info>

Import new contacts or update existing contacts from a CSV or XLSX file. PolicyDen matches existing contacts by phone.

## Before you start

- Use one CSV or XLSX file up to 10MB, with column headers in the first row.
- Include First Name, Last Name, Phone, and fields listed under **Required Fields** in your import dialog.
- Required agency fields apply when they are required for all products.
- Optional **Agent Email** values must match users in your agency. New contacts without one are assigned to you.

<Warning>Importing can change existing contacts. Nonblank values replace matching fields; blank cells preserve existing values. Export a copy before making broad changes.</Warning>

## Import your file

<Steps>
  <Step title="Open the import dialog">
    In **Contacts**, select the import icon labeled **Import Contacts**.
    <Frame>
      <img src="/images/contacts/import-upload.png" alt="Import Contacts dialog with Download template highlighted." />
    </Frame>
  </Step>
  <Step title="Prepare your spreadsheet">
    Select **Download template** for current headers and sample values. Replace the sample row with your contact data.
  </Step>
  <Step title="Upload your file">
    Drop your file into the upload area. For a workbook with multiple sheets, choose **Select Sheet**.
  </Step>
  <Step title="Match your columns">
    Review **Required Fields** and **Optional Fields**. Select the matching column for each field you want to import.

    Matching headers are selected automatically. Use **-- None --** for optional fields you want to leave out.
  </Step>
  <Step title="Start the import">
    Select **Import Contacts**. Keep the window open while **Importing** shows progress.
  </Step>
  <Step title="Review the results">
    Review **Import Complete** or **Import Stopped**, including **Issues**, then select **Done**.
  </Step>
</Steps>

## What you'll see

Results show imported, updated, and skipped counts; new contacts start as **Lead**, and existing assignments stay unchanged without an agent email.

## If it didn't work

<AccordionGroup>
  <Accordion title="Import Contacts is disabled">
    Map every required field. If your workbook has several sheets, select the sheet before mapping columns.
  </Accordion>
  <Accordion title="Some rows were skipped">
    Review each row under **Issues**. Correct missing values, invalid formats, or unknown agent emails using [import troubleshooting](/fix/import-problems).
  </Accordion>
  <Accordion title="The import stopped">
    Some rows may already be saved. Run the file again to finish; matching phone numbers update saved contacts.
  </Accordion>
</AccordionGroup>
