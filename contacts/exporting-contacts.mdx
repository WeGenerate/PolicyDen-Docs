Download contacts you can access as a CSV file. Choose the records and fields before exporting.

## Before you start

- Apply any filters or date range you need in **Contacts**.
- Admins and Agency Owners can select row checkboxes to export specific contacts.

<Steps>
  <Step title="Open the export dialog">
    In **Contacts**, select the export icon with the **Export Contacts** tooltip.

    <Frame caption="Choose records and fields before downloading.">
      <img src="/images/contacts/exporting-options.png" alt="Export Contacts dialog showing Type, CSV format, and Fields." />
    </Frame>
  </Step>
  <Step title="Choose the records">
    Under **Type**, select **All** or **Selected**.

    **All** uses applied filters, the date range, and **My Contacts**. **Selected** uses the rows you selected.
  </Step>
  <Step title="Choose the fields">
    Under **Fields**, select the information to include.

    Use **Search fields...** to find a field, or **Select All** to include every available field.
  </Step>
  <Step title="Download the file">
    Select **Export**.
  </Step>
</Steps>

The default fields are **First Name**, **Last Name**, **Email**, **Phone**, **Date of Birth**, and **Medicare Number**. Additional choices include addresses, assignment, creation date, and custom fields.

The list’s **Search** text does not narrow an **All** export. Use **Filters** to restrict exported records instead.

## What you'll see

Your browser downloads **contacts.csv**, containing the selected fields and accessible records.

## If it didn't work

<AccordionGroup>
  <Accordion title="Selected is unavailable">
    Select row checkboxes before opening the dialog. Only Admins and Agency Owners have row selection controls.
  </Accordion>
  <Accordion title="Export is unavailable">
    Select at least one field. The button is also unavailable while an export is running.
  </Accordion>
  <Accordion title="No download appeared">
    Wait for the request to finish and check your browser’s downloads. If it failed, reopen the dialog and try again.
  </Accordion>
</AccordionGroup>
