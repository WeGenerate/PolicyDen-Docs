The **Contacts** page is the home for every lead and client your agency works with. From a single table you can search your book, narrow it with filters, jump into any contact's profile, and — if you're an admin — import, export, and run bulk actions.

## Open the Contacts page

Click **Contacts** in the sidebar. You land on the full contact list, sorted by most recently created.

## The table

Each row is one contact. The **Contact** column is pinned on the left so the name stays visible as you scroll sideways.

Out of the box, the table shows:

- **Contact** — full name. Click the name to open the profile.
- **Phone**, **Date of Birth**, **Medicare Number** — common system fields.
- **Physical State** and **Physical City** — from the contact's address.
- **Agent** — the user assigned to the contact.
- **Agency** — which agency the contact belongs to (relevant for multi-agency users).

You can add, remove, and reorder columns from the column picker.

### Inline editing

Hover any editable cell and click to edit in place. Phone, email, date of birth, address fields, Medicare number, and the assigned agent can all be updated without leaving the list.

### Open a contact

Click the contact's name to open their profile. See [Contact profile](/contacts/contact-profile) for what you'll find there.

## Toolbar

The toolbar across the top of the table groups everything you do against the list.

| Control | What it does |
| ------- | ------------ |
| **Search** | Filters by name, email, or phone as you type. |
| **Filters** | Add one or more field conditions to narrow the list. |
| **Reset filters** | Clears all active filters. |
| **Sort** | Sort by one or more columns. |
| **Customize columns** | Choose which columns are visible and in what order. |
| **My Contacts** | Agents only. Show only contacts assigned to you. |
| **Date range** | Limits the list to contacts created in the selected window. |

The toolbar also includes three entry points with dedicated pages:

- **Add Contact** opens the search-then-create flow. See [Creating contacts](/contacts/creating-contacts).
- **Export** downloads the current list as a CSV. See [Exporting contacts](/contacts/exporting-contacts).
- **Import** (admins only) bulk-uploads contacts from CSV or Excel. See [Importing contacts](/contacts/importing-contacts).

## Filters

Click **Filters** to add one or more conditions. You can filter by:

- **Name**, **Agent**, **Agency**.
- System fields like phone, email, date of birth, gender, state, city, county, ZIP, and Medicare number.
- Any custom fields your agency has defined.

Each filter uses operators that match the field type — for example, **equals** and **contains** for text, **before** / **after** for dates, **is empty** / **is not empty** to find missing data.

<Tip>
  Save a filter combination and its columns as a reusable view in [Saved filters](/customization/saved-filters).
</Tip>

## Sorting

Click a column header to sort by that column. Click **Sort** in the toolbar to sort by multiple columns at once.

## Selecting contacts

Admins see a checkbox column. Use it to select one or more rows, then run a [bulk action](/contacts/bulk-actions) against the selection.
