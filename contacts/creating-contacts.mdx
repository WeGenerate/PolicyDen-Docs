Create a contact from their phone number and name. PolicyDen checks for an existing record before opening the new-contact fields.

## Before you start

- Have the contact’s phone number, first name, and last name ready.
- Search results only include contacts you can access.

<Steps>
  <Step title="Open the contact form">
    In **Contacts**, select **Add Contact**.

<Frame caption="Add New Contact dialog with the Phone field and Search button.">
  <video className="w-full rounded-xl motion-reduce:hidden" autoPlay muted loop playsInline controls preload="metadata" poster="/images/contacts/creating-search.png" src="/videos/contacts/creating-search.mp4" aria-label="Add New Contact dialog with the Phone field and Search button." />
  <img className="hidden motion-reduce:block" src="/images/contacts/creating-search.png" alt="Add New Contact dialog with the Phone field and Search button." />
</Frame>
  </Step>
  <Step title="Enter the phone number">
    In **Phone**, enter the number you use to reach the contact.
  </Step>
  <Step title="Check for an existing record">
    Select **Search**.

    If a matching contact appears, select their name to open the existing profile. Continue only when no match appears.
  </Step>
  <Step title="Enter the first name">
    In **First Name**, enter the contact’s first name.
  </Step>
  <Step title="Enter the last name">
    In **Last Name**, enter the contact’s last name.
  </Step>
  <Step title="Create the record">
    Select **Add Contact**.
  </Step>
</Steps>

## What you'll see

The new contact’s profile opens, ready for you to [add their remaining details](/contacts/editing-contact-details).

## If it didn't work

<AccordionGroup>
  <Accordion title="Search is unavailable">
    Enter a valid phone number. The search stays unavailable while the number is incomplete or a search is running.
  </Accordion>
  <Accordion title="An existing contact appears">
    Open the matching record. The form doesn’t offer new-contact fields while that phone number has a match.
  </Accordion>
  <Accordion title="Add Contact is unavailable">
    Check that both name fields contain text and the phone number is valid. Wait for any current save to finish.
  </Accordion>
</AccordionGroup>
