The **Tasks** page is a single list of every follow-up, callback, and to-do you and your teammates have scheduled. Filter it to focus on your own work or switch to a wider view to see what the team is up to.

</Frame>

## Open tasks

Click **Tasks** in the sidebar. You'll see the task list with status presets across the top.

## Status presets

The row of presets at the top of the page lets you switch between slices of the task list. Each one shows a count next to it so you can see the workload at a glance.

| Preset | Shows |
| ------ | ----- |
| **All Tasks** | Every task in your agency you have access to. |
| **Open** | Tasks that haven't been started. |
| **In Progress** | Tasks someone is actively working on. |
| **Completed** | Tasks marked as done. |
| **Canceled** | Tasks that were canceled before completion. |

Click any preset to filter the list.

## Task columns

Each row in the table represents one task. The default columns are:

| Column | What it shows |
| ------ | ------------- |
| **Task Name** | The task title. |
| **Due Date** | The scheduled due date. |
| **Priority** | Low, Medium, or High. |
| **Status** | Open, In Progress, Completed, or Canceled. |
| **Assigned To** | The agent responsible for the task. |

You can edit any of these fields inline by clicking the value in the row. See [Manage tasks](/tasks/managing-tasks) for the full list of actions.

## Search and filter

### Search

The **Search** box at the top-left matches task titles. Type a few characters and the list narrows as you go.

### Filter

Click **Filter** to add one or more conditions:

- **Task Name** — text contains a keyword.
- **Due Date** — on, before, or after a date.
- **Priority** — High, Medium, or Low.
- **Status** — Open, In Progress, Completed, or Canceled.
- **Assigned To** — one or more Agents.

### Sort

Click any column header to sort the list by that column. Click again to reverse the direction.

### Columns

Click **Columns** to show or hide columns. Your choice is remembered per user.

## Your tasks vs team tasks

The task list always shows every task in your agency you have access to. To see only your own, filter **Assigned To** to yourself. To see a teammate's workload, pick their name instead.

<Tip>
  Save a filter view named "My open tasks" — assigned to you, status Open — so you can jump to it in one click. See [Saved filters](/customization/saved-filters).
</Tip>

## Row actions

Each row has a menu on the far right with:

- **View** — open the task details page.
- **Delete** — remove the task (with a confirmation).

You can also select multiple tasks with the checkboxes on the left to run [bulk actions](/tasks/managing-tasks#bulk-actions) like complete, assign, or delete.
