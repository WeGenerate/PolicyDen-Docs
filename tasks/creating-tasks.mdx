Create a task for work you need to complete. You can add details, choose a due date, and attach supporting files.

## Before you start

- Choose a short title that describes the next action.
- Admins and Agency Owners can choose an owner; Agents create tasks assigned to themselves.

<Steps>
  <Step title="Open the task form">
    In **Tasks**, select **Add Task**.

    <Frame>
      <img src="/images/tasks/create-form.png" alt="Tasks workspace with the relevant control highlighted." />
    </Frame>
  </Step>
  <Step title="Enter a task title">
    In **Task Title**, enter the action to complete.
  </Step>
  <Step title="Add task details">
    In **Add Description...**, enter the information needed to finish the task.
  </Step>
  <Step title="Choose a due date">
    Select **Due Date** and choose when the task is due.
  </Step>
  <Step title="Set the priority">
    Select the priority control and choose **Low**, **Medium**, or **High**.
  </Step>
  <Step title="Create the task">
    Select **Create Task**. The task starts in **To Do**.
  </Step>
</Steps>

If your agency has task templates, select **Template** before entering details. A selection fills the title and description; review them before saving.

## What you'll see

The new task appears in **Tasks**, ready for you or its assigned owner to update.

## If it didn't work

<AccordionGroup>
  <Accordion title="“Please enter a task title.”">
    Enter a title of 255 characters or fewer. Keep the description within 10,000 characters.
  </Accordion>
  <Accordion title="The template picker is missing">
    The picker appears only when task templates exist. Ask an Admin to [create a task template](/settings/task-templates).
  </Accordion>
  <Accordion title="“Failed to create task.”">
    Check your connection and reopen **Tasks** before trying again, so you can check whether the task was created.
  </Accordion>
  <Accordion title="A file failed to upload">
    The task can be created even if an attachment fails. Open it and use **Attach file** to try again.
  </Accordion>
</AccordionGroup>
