Select policy rows to assign a writing agent or archive records together. Review the selection before applying either action.

## Before you start

- Use **Search**, **Filters**, and the date range to narrow the list.
- Confirm that every selected policy should receive the same change.

## Assign a writing agent

<Steps>
  <Step title="Select the policies">
    In **Policies**, select the checkbox beside each policy to change.
        The action bar shows the selected count.
        <Frame>
      <img src="/images/policies/bulk-selected.png" alt="Policies list with selected rows and the bulk action bar visible." />
    </Frame>
  </Step>
  <Step title="Open agent assignment">
    Select **Assign To** in the action bar.
  </Step>
  <Step title="Choose the agent">
    In **Select agent**, choose the writing agent.
  </Step>
  <Step title="Apply the assignment">
    Select **Assign**.
    A successful change shows **Agent assigned**.
  </Step>
</Steps>

## Archive selected policies

<Warning>Archiving removes selected policies from the pages. Check the selection carefully before confirming.</Warning>

<Steps>
  <Step title="Review the selection">
    Check the selected policy numbers and the count in the action bar.
  </Step>
  <Step title="Open archive confirmation">
    Select **Archive** in the action bar.
  </Step>
  <Step title="Confirm the archive">
    In **Archive Policies**, select **Archive Policies**.
    Choose **Cancel** if the selection needs correction.
  </Step>
</Steps>

## What you'll see

Assigned policies show the chosen writing agent; archived policies disappear from the list after the success message.

## If it didn't work

<AccordionGroup>
  <Accordion title="No selection checkboxes appear">
    Row selection is available to Admins and Agency Owners. Ask an Admin to make the bulk change.
  </Accordion>
  <Accordion title="Assign is unavailable">
    Choose an agent in **Select agent** before submitting.
  </Accordion>
  <Accordion title="The bulk action failed">
    Read the error message and refresh the list to check which records changed before retrying.
  </Accordion>
</AccordionGroup>
