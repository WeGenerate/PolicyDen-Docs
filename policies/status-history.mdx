<Info>**Who can do this:** Agents, Admins, and Agency Owners with access to the policy.</Info>

Use the policy profile to compare the current status with entries in **Status Log**. A detected status message may differ from the current status.

<Steps>
  <Step title="Open the policy">
    In **Policies**, select the policy number you want to review.
  </Step>
  <Step title="Read the current status">
    Check the status badge beside the policy number and the **Status** field when shown.
    Available statuses depend on the product.
  </Step>
  <Step title="Expand the log">
    Select **Status Log** to show its entries.
        <Frame>
      <img src="/images/policies/status-log.png" alt="Policy profile with Status Log expanded." />
    </Frame>
  </Step>
  <Step title="Review each entry">
    Read the entry's result, date, and time.
    Entries may show a status change, no change, a detected status, or a failed check.
  </Step>
</Steps>

## What you'll see

The log shows available status-check results, including the previous and new status when a change is recorded.

## If it didn't work

<AccordionGroup>
  <Accordion title="No status checks yet">
    No entries are available for this policy. Return to the profile to review its current status.
  </Accordion>
  <Accordion title="Status check failed">
    Read the entry's error message. If you need help, send support@policyden.com the policy number and error text.
  </Accordion>
  <Accordion title="A detected status differs from the current status">
    A message beginning **Detected** and ending **no change applied** does not confirm that the current status changed.
    Ask an Admin to review the policy before editing its status.
  </Accordion>
</AccordionGroup>
