<Info>**Who can do this:** Admins and Agency Owners in agencies with the dialer enabled.</Info>

Create a queue and choose who receives its calls.

## Before you start

- Prepare [phone numbers](/dialer/phone-numbers), [dispositions](/dialer/dispositions), and a [script](/dialer/scripts).
- Decide which agents should receive calls.

## Create the queue

<Steps>
<Step title="Open your queues">
  In **Dialer**, select **Queues**.
</Step>
<Step title="Add a queue">
  Select **Add Queue**, enter a unique **Name**, then select **Add Queue**.
</Step>
<Step title="Open queue settings">
  Open the queue to edit its settings.
</Step>
</Steps>
<Frame>
<img src="/images/dialer/queues.png" alt="Queue list showing the agency’s queues and their status." />
</Frame>

## Configure the queue

<Steps>
<Step title="Set general details">
  In **General Settings**, enter your settings, then select **Save**.
</Step>
<Step title="Assign a number">
  In **Assigned Numbers**, select **Add Number**, then choose **Existing Number** or **Buy New Number**.
</Step>
<Step title="Choose your agents">
  In **Agents**, select agents, set their limits, then select **Save**.
</Step>
<Step title="Choose call outcomes">
  In **Dispositions**, choose a **Disposition Group** or individual dispositions, then select **Save**.
</Step>
<Step title="Choose a script">
  In **Script**, choose a **Call Script**, then select **Save**.
</Step>
</Steps>

| Setting | What it does | Default | Who can change it |
| --- | --- | --- | --- |
| **Queue Name** | Names the queue; must be unique in your agency. | Entered at creation | Admin, Agency Owner |
| **Internal Name** | Optional name hidden from agents. | Empty | Admin, Agency Owner |
| **Product** | Associates a product with calls. | None | Admin, Agency Owner |
| **Priority** | Higher-priority queues receive the next available agent first; accepts 0–100. | 0 | Admin, Agency Owner |
| **Weight** | Sets agent routing weight; accepts 0–100. | 0 | Admin, Agency Owner |
| **Daily Cap** | Limits agent calls per day; accepts 1–1,000 when set. | No cap | Admin, Agency Owner |
| **CPA Cap** | Sets an agent’s cost-per-acquisition limit; accepts $0.01–$100,000 when set. | No cap | Admin, Agency Owner |

Use **Remove All** to clear agent selections. **Remove from queue** detaches a number; each number can serve one queue.

Configure [routing and hours](/dialer/queue-routing-and-hours) and, for publishers, [pay-per-call settings](/dialer/pay-per-call).

The header’s **Active**/**Inactive** switch changes availability. The list menu also offers **Edit**, **Pause**/**Activate**, and **Delete**.

<Warning>Deleting a queue is permanent. Use **Pause** to stop it temporarily.</Warning>

## What you'll see

Your queue shows its assigned numbers, agents, and saved settings.

## If it didn’t work

<AccordionGroup>
<Accordion title="The name is rejected">
  Choose a different name. The app reports “A queue with this name already exists.”
</Accordion>
<Accordion title="A number is missing">
  Only numbers not assigned to a queue appear under **Existing Number**. Review its routing in **Phone Numbers**.
</Accordion>
<Accordion title="An agent receives no calls">
  Check queue status, agent selection, caps, and [routing settings](/dialer/queue-routing-and-hours).
</Accordion>
</AccordionGroup>
