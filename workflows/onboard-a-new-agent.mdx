<Info>**Who can do this:** Admins and Agency Owners in agencies with a Users page. Individual agent accounts do not have Users.</Info>

Invite an agent and prepare their licenses and calling access. Allow about 20 minutes per agent.

## Before you start

- Have the agent’s email and National Producer Number (NPN) ready. [See the glossary](/start/glossary).
- Decide their role, sales channel, and employment type.
- Calling setup requires the dialer to be enabled.

## 1. Send the invitation

In **Users**, select **Add User**. Enter their details and choose **Agent** as the role; saving sends an email invitation.

<Frame>
  <img src="/images/workflows/onboard-a-new-agent-1.png" alt="Add User dialog with the Role field highlighted." />
</Frame>

[Full steps: Invite an agent →](/settings/users-and-roles)

## 2. Check how they work

Review **Sales Channel** and **Employment Type**. For Telesales, also set **Work Location**, including **Remote** when appropriate.

On an existing profile, these settings are under **Details** in **Employment**.

<Frame>
  <img src="/images/workflows/onboard-a-new-agent-2.png" alt="Check how they work: current workspace and navigation." />
</Frame>

[Full steps: Review user profiles →](/settings/user-profiles)

## 3. Set licenses and contracts

Open the agent’s **Licensed States** and **Contracts**. Set states per product and the carriers they write through; use their main agency to edit these.

<Frame>
  <img src="/images/workflows/onboard-a-new-agent-3.png" alt="Set licenses and contracts: current workspace and navigation." />
</Frame>

[Full steps: Set licenses and contracts →](/settings/licensed-states-and-contracts)

## 4. Assign call access

For inbound calling, assign the agent to the appropriate queues. For outbound calling, assign an active campaign; marketplace agencies use **Manage Access** on the queue card.

[Full steps: Assign marketplace access →](/marketplace/managing-queue-access)
[Full steps: Configure campaigns →](/dialer/campaigns)

<Frame>
  <img src="/images/workflows/onboard-a-new-agent-4.png" alt="Assign call access: current workspace and navigation." />
</Frame>

[Full steps: Configure queues →](/dialer/queues)

## 5. Prepare practice and handoff

For a learning agent, turn on **Training** under **Employment**. In dialer-enabled agencies, this gives the agent listen-only **Live Monitor** access.

Send [Your first session](/quickstart) so they can sign in, review their profile, and record a follow-up.

<Frame>
  <img src="/images/workflows/onboard-a-new-agent-5.png" alt="Prepare practice and handoff: current workspace and navigation." />
</Frame>

[Full steps: Use Live Monitor →](/dialer/live-monitor)

## If it didn't work

<AccordionGroup>
  <Accordion title="The agent cannot edit licenses">
    An Admin must use the agent’s main agency for changes. [Review licenses](/settings/licensed-states-and-contracts).
  </Accordion>
  <Accordion title="Training access is missing">
    Check **Training**, the dialer feature, and account type. Individual agent accounts do not have **Live Monitor**.
  </Accordion>
</AccordionGroup>
